# HRAF-2022

Research compendium for Liu, C. A Cross-Cultural Analysis of Toolmaking Skill Acquisition in Non-Industrial Societies. Cross-Cultural Research. https://doi.org/10.1177/10693971251415454.



## Getting Started

Please open the Rproj file instead of the Rcode directly to make sure relative paths work!



## File Structure

The repository is organised into four main directories: code, data, figure, and manuscript.



### code

* `Descriptive Analysis.R` ... This is the R script generating the main results and figures of this paper.



### data

* `Coordinate data.txt`... This file documents the coordinate information of all cultures indexed in eHRAF.

* `craft-learning.csv`... This is the main data file documenting attributes analyzed in the paper.

* `ehraf-ccr.csv`... This csv file is the output file for eHRAF and D-Place data merging.

* `toollearning\_geo.csv`... This csv file documents the coordinate information of societies surveyed in this paper.



### figure

* `how.jpg` ... This is Fig.6 in the manuscript.

* `Map.pdf` ... This is Fig.1 in the manuscript.

* `Map.tiff` ... This is the journal submission version of Fig.1 in the manuscript.

* `missing.jpg` ... This is Fig.8 in the manuscript.

* `upset.jpg` ... This is Fig.9 in the manuscript.

* `what.jpg` ... This is Fig.2 in the manuscript.

* `when.jpg` ... This is Fig.5 in the manuscript.

* `where.jpg` ... This is Fig.4 in the manuscript.

* `who.jpg` ... This is Fig.3 in the manuscript.

* `why.jpg` ... This is Fig.7 in the manuscript.



### manuscript

* `apa.csl` ... This is the APA citation styleguide.

* `bibliography.bib` ... This is the reference file.

* `manuscript.pdf` ... This is the pdf file of the manuscript.

* `manuscript.Rmd` ... This is the RMarkdown file of the manuscript.

* `Appendix.pdf` ... This is the pdf file of the compiled ethnographic sources.

* `Appendix.Rmd` ... This is the RMarkdown file of the Appendix.pdf.
